# Changelog

## 1.4.0

- Initial release of the package.
- Environments: grid world, cliff walking and taxi, with a registry.
- Agents: Q-learning, SARSA, Expected SARSA and Double Q-learning.
- Exploration schedules: constant, linear, exponential, inverse-time and half-life.
- Training loop with metrics, periodic and best checkpoints, greedy evaluation and solve thresholds.
- Compare and learning rate sweep experiments.
- Text rendering of policies and optional learning curve plots.
- `qnavi` command line interface and Makefile build targets.
